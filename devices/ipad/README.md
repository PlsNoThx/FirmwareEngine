# iPad (broken screen)

## Identify it first
- Model number (A1xxx) on the back.
- **What's broken?** Cracked glass with the picture still fine, touch not working, or a dead or black LCD?

## Options
### If the LCD still shows a picture
- **Use it as-is:** dashboard or photo frame. If touch is dead, drive it with a Bluetooth keyboard (Full Keyboard Access on iOS 13.4+) or Switch Control.
- Older models (A5 to A11 chips, such as the iPad 2 through iPad 7) can be jailbroken with checkm8-based tools for more control.

### Reuse the LCD panel as an HDMI monitor
- The iPad 3/4 and Air panels (9.7-inch, 2048x1536, LG LP097QX1 family) are a well-known DIY monitor build.
- Needs an eDP-to-HDMI driver board for that panel, which is cheap and sold online.
- Gives you a high-resolution screen for the Mac mini, or a second display.

### Salvage
- The battery is a large LiPo. Pry it out carefully (adhesive, puncture risk), and only if it isn't swollen.
