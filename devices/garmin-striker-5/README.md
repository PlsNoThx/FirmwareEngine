# Garmin Striker 5

A fish finder with CHIRP sonar, GPS and a 5-inch screen.

## Assessment
- The firmware is proprietary and signed, and there's no custom-firmware community, so reprogramming it isn't realistic.
- Unverified: I believe the Striker line has no NMEA 0183/2000 output for sharing GPS or sonar data. Check the manual or the cable pinout.
- If it works, its best use is probably fishing or selling it. Used units still sell.

## If it's dead
- Salvage the sunlight-readable 5-inch display (identifying the panel needs a teardown) and the GPS module.
- Reusing the sonar transducer means building your own transmit/receive electronics. That's an advanced project.
