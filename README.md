# FirmwareEngine

Repurposing old electronics: new firmware, new jobs, and salvaged parts.

## Workbench
- Serial cables and USB-serial adapters
- ESP32 dev board
- Arduino Uno (also usable as an SPI flash programmer)
- Soldering and general hardware tools
